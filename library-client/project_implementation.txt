================================================================================
LIBRARY PROJECT - DETAILED IMPLEMENTATION OVERVIEW
================================================================================

This document provides a comprehensive summary of the architecture, data models,
backend structure, frontend components, and infrastructure configuration for the
Library Project.

--------------------------------------------------------------------------------
1. GLOBAL ARCHITECTURE & TECH STACK
--------------------------------------------------------------------------------
The project follows a decoupled client-server architecture:
- Frontend Client: Angular 18 (Standalone Components, Signals, CSS styling).
- Backend API: ASP.NET Core Web API (.NET 9.0) exposing REST endpoints.
- Database: Microsoft SQL Server 2022 (relational storage and database-level translations).
- Blob Storage: MinIO (S3-compatible) for hosting cover image uploads.
- Infrastructure: Docker Compose for local SQL Server and MinIO services.

Data Flow Diagram:
[ Angular 18 Client ]
        │  ▲
        │  │ HTTP Requests (with JWT & Accept-Language headers)
        ▼  │
[ ASP.NET Core API ]
        │         │
        │ EF Core │ AWS S3 SDK
        ▼         ▼
  [ SQL Server ] [ MinIO Storage ]

--------------------------------------------------------------------------------
2. BACKEND LAYER (ASP.NET CORE WEB API)
--------------------------------------------------------------------------------
The backend project is located in the '/Library' directory.

2.1 Data Models & EF Core Context (Models & DataContext)
The domain entities represent the library database schema:
- User (ApplicationUser): Derived from IdentityUser. Manages login credentials and roles.
- Book: Primary entity containing ISBN, PageCount, ImageUrl, Published Date, and AuthorId.
- Author: Author info with relational link to Books.
- Genre: Book genres.
- BookGenre: Composite key table (BookId, GenreId) establishing a many-to-many relationship.
- Country: Model for Author nationalities.
- Review & Reviewer: Reviews with text rating (1-5 stars) linked to Book and Reviewer.
- BiBookAnalytics: Analytics table (BookId, AverageRating, TotalReviews, LastUpdated).
  Configured as a 1-to-1 relationship with Book with Cascade Delete.

Database-Level Localization (Multi-Language Slovak "SK", English "EN", Greek "GR"):
Dynamic translations are stored directly in the database using translation tables:
- BookTranslation: BookId, LanguageCode, Title, Description.
- AuthorTranslation: AuthorId, LanguageCode, Name, Surname.
- GenreTranslation: GenreId, LanguageCode, Name.
Unique composite indices on (EntityId, LanguageCode) prevent duplicate translations.

2.2 Controllers (Web API Endpoints)
The RESTful Controllers manage client-server communication:
- AuthController: Registration, Login (generates JWT tokens).
- AuthorController: Retrieves list of authors.
- BlobsController: Media actions (downloading uploaded book covers).
- BookController: CRUD actions for Books.
- CountryController: Retrieves author countries.
- GenreController: Retrieves book genres.
- LocalizationController: Exposes configuration for frontend localization.
- ReviewController: Review creation and management.
- ReviewerController: Reviewer account actions.

2.3 Core Services (Business Logic)
- S3BlobService (IBlobService): Handles S3 connection with MinIO client.
  - Ensures default bucket "library-covers" exists.
  - Uploads cover images with unique GUIDs.
  - Downloads / Deletes media.
- TokenService (ITokenService): Generates JWT Bearer tokens containing User ID, Username, and Role claims.
- LanguageService (ILanguageService): Dynamically resolves client language by parsing incoming 'Accept-Language' header (defaults to "SK").
- BookAnalyticsService (IBookAnalyticsService): Logic to dynamically calculate and update book ratings.
- PasswordHasher: Secure cryptographic password checks via PBKDF2 hashing.

2.4 Program.cs & Middleware Configuration
- Program.cs: Sets up dependency injections, DB context options, Identity config, JWT authentication schemes, Serilog configurations, and seeds data.
- GlobalExceptionHandlingMiddleware: Intercepts all runtime exceptions, returns custom ErrorResponse JSON, and logs details.

--------------------------------------------------------------------------------
3. FRONTEND LAYER (ANGULAR 18 STANDALONE CLIENT)
--------------------------------------------------------------------------------
The client project is located in '/library-client' or the nested 'library-client' subdirectory.

3.1 Application Entry Points
- app.ts / app.config.ts: Configuration provider defining HTTP Client, routing, and interceptors.
- app.routes.ts: Defines lazy-loaded route endpoints:
  - '/' (Landing Page)
  - '/authors' (Authors Page)
  - '/genres' (Genres Page)
  - '/auth' (Login / Registration Page)
  - '/admin' (Protected Administration Control Panel)

3.2 Main Components & Views (features)
- LandingPage: Displayed at root. Includes search querying, filtering by genre, book detail overlay modals, and reviewer submission forms.
- AuthorsPage: Displays list of authors. Generates visually appealing avatars using unique CSS gradients.
- GenresPage: Lists genres.
- AdminPage: Admin CRUD panel for adding, editing, and deleting books. Features drag-and-drop book cover uploading directly to S3 storage.
- AuthPage: Login and signup pages with client validation.

3.3 State Management & Infrastructure Services
- Angular Signals: Manages reactive application state (e.g. books, genres, user auth, selected localization).
- toObservable (RxJS Interop): Combines route query parameters and localization state to trigger automatic catalog refreshes on language switches.
- jwtInterceptor: Appends Authorization (Bearer JWT) and Accept-Language header metadata to every HTTP request.
- adminGuard: Guard validation checking if authenticated user roles allow access to '/admin'.
- LocalizationService: Manages active client language cache inside localStorage.

--------------------------------------------------------------------------------
4. INFRASTRUCTURE & ORCHESTRATION (DOCKER COMPOSE)
--------------------------------------------------------------------------------
The infrastructure is defined inside 'docker-compose.yml':
- MS SQL Server 2022: Exposes port 1433 for relational data.
- MinIO: Exposes port 9000 (S3 API Client) and port 9001 (Web Console Client) for local object storage.
